# Self-hosted fonts

The platform is deployed on isolated networks where Google Fonts is unreachable,
so the four families in the design system ship with the app.

| File | Family | Weights | License |
| --- | --- | --- | --- |
| `public-sans-latin.woff2`, `public-sans-latin-ext.woff2` | Public Sans | 400–700 variable | SIL Open Font License 1.1 |
| `source-code-pro-latin.woff2` | Source Code Pro | 400–600 variable | SIL Open Font License 1.1 |
| `fraunces-latin.woff2`, `fraunces-latin-italic.woff2` | Fraunces | variable, roman + italic | SIL Open Font License 1.1 |
| `literata-latin.woff2`, `literata-latin-italic.woff2` | Literata | variable, roman + italic | SIL Open Font License 1.1 |

All four families are licensed under the SIL Open Font License, Version 1.1
(<https://openfontlicense.org>). The license permits bundling and self-hosting;
the font files may not be sold on their own.

- Public Sans — <https://github.com/uswds/public-sans>
- Source Code Pro — <https://github.com/adobe-fonts/source-code-pro>
- Fraunces — <https://github.com/undercasetype/Fraunces>
- Literata — <https://github.com/googlefonts/literata>
